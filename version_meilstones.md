# Versionsmeilensteine

Hier werden die geplanten Meilensteine der verschiedenen Versionen vorausgeplant
und tabellarisch aufgelistet.

| Meilenstein | geplant in Version | Beschreibung |
| --- | --- | --- |
| Grundfunktionen & Härtung | 1.0 | Monorepo-Struktur, API + Web-Frontend, Arduino- und ESP32-Libs, Lizenz, Tests/CI, Sicherheits-Fixes|
| Filterbasierter CSV-Abruf | 1.1 | Filterbasierter Abruf von Messdaten als CSV – über die API und im Dashboard |
| Dashboard                 | 1.2 | Dashboard mit ein paar wichtigen Plots und einer filterbasierten Export GUI |
| Dashboard                 | 1.3 | Anleitungen |
| LDAP-Auth                 | 1.5 | LDAP-Auth für kommende Funktionen |
| Datenbankzugriff          | 1.5 | Bearbeiten von Datenbankeinträge nach LDAP-Auth |
| Registrieren von Geräten  | 1.6 | Registrieren von Geräten über TTN-Rest-API für User |
| Benutzereinstellungen      | 1.7 | Zeitzone und dunkle Darstellung pro Benutzer, einheitliche Zeitanzeige, Datengruppen als Teilmenge der LDAP-Gruppen |
| Messwerte nach Gruppen     | 1.8 | Messwerte einer Datengruppe zuordnen; lesen und ändern nur mit Rolle **und** Gruppe |
